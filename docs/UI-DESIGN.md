# تصميم الواجهة (v0.1)

**المرجع:** تخطيط مديري التحميل المألوف (IDM/Ezoo): قائمة علوية، شريط أدوات بأيقونات ونص، تصنيفات
جانبية، جدول تحميلات، شريط حالة. **لا أصول منسوخة:** كل الأيقونات رموز SVG مرسومة يدوياً داخل
`index.html`، والألوان والخطوط من نظام هذا المشروع، ولا صور أو نصوص من أي منتج آخر.

## المبادئ
1. **الخفة أولاً:** بلا إطار JavaScript ولا مكتبات (HTML/CSS/JS عادي، نحو 115 KB غير مضغوطة، تُحمَّل من داخل البرنامج لا من الإنترنت). الجدول افتراضي
   (يرسم الصفوف المرئية فقط: 34 صفاً مهما كان العدد)، التحديث بالتغييرات فقط (`list(since)`)، والرسم
   مرة واحدة لكل إطار (`requestAnimationFrame`). الأرقام في `docs/BENCHMARKS.md` §3.
2. **العربية أولاً:** RTL كامل، كل نص في `i18n.js` بالعربية والإنجليزية، الأرقام والروابط والمسارات `dir="ltr"`.
3. **لا أزرار ميتة:** أي أمر غير مدعوم في المحرّك لا يظهر كأنه يعمل. في v0.1 كل أوامر القوائم تعمل.
4. **الأمان مرئي:** نافذة موافقة كاملة قبل تنزيل أدوات الفيديو؛ «فتح الملف» يرفض تشغيل البرامج والسكربتات ويفتح المجلد بدلاً منها.

## العناصر
| العنصر | ماذا فيه |
|---|---|
| القائمة العلوية | ملف، تحميلات، عرض، مساعدة — مع اختصارات لوحة المفاتيح (Ctrl+N إضافة، Ctrl+Shift+N فيديو، Ctrl+, الإعدادات، Space إيقاف/استكمال، Delete، Ctrl+A، Enter الخصائص، F1) |
| شريط الأدوات | إضافة رابط، تحميل فيديو، استكمال، إيقاف، إيقاف الكل، حذف، مسح المكتملة، المجدول، الإعدادات |
| التصنيفات | الكل، قيد التحميل، غير المكتملة، المكتملة، الفاشلة + بالنوع (مضغوطات، مستندات، موسيقى، فيديو، برامج، صور، أخرى) + مهام الفيديو والقوائم، مع عدد كل تصنيف |
| الجدول | الاسم مع أيقونة النوع، الحجم، التقدم، السرعة، الوقت المتبقي، الحالة؛ تحديد متعدد (Shift/Ctrl)، قائمة بالزر الأيمن، نقرة مزدوجة للخصائص |
| مهام الفيديو | تقدم القائمة كلها (عدد العناصر، لا بايتات العنصر الحالي)، حالة كل عنصر، إيقاف/استكمال/إعادة الفاشل |
| نافذة الفيديو | فحص الرابط، الجودة (360p…2160p، أفضل حتى 4K، صوت فقط)، اختيار عناصر القائمة (الكل/لا شيء) |
| الإعدادات | عام (اللغة، السمة، المجلد)، التحميلات (عدد التحميلات معاً 1–8، الاتصالات 1–32، حد السرعة الكلي)، الفيديو (الجودة الافتراضية، حالة الأدوات وإصداراتها) |
| المجدول | نافذة زمنية (من/إلى، تمتد لليوم التالي إن لزم) وأيام الأسبوع؛ خارجها تنتظر التحميلات |
| شريط الحالة | التحميلات النشطة، السرعة الكلية، العدد، المحدد |
| السمات | فاتح، داكن، حسب النظام |

## الاختبار
`node scripts/ui/ui_e2e.mjs` (Chrome حقيقي بلا واجهة، 13 فحصاً: العربية/RTL، تبديل اللغة، الموافقة على
الأدوات، القوائم بلا 8K، الإعدادات، المجدول، فتح الملف ورفض البرامج، السلاسة مع 100/1000/3000 تحميل،
ولا أخطاء JavaScript)، و`cd crates/eid-gui/ui && node --test` (منطق الواجهة). على Windows:
`scripts/gui_smoke.ps1` يشغّل `EidDownload.exe` الحقيقي مع المحرّك ويلتقط صوراً.
**لم تُجرَّب يدوياً على Windows بعد** (`docs/OWNER-ACTIONS.md` §1).
