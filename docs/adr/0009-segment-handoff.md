# ADR-0009: تسليم الأجزاء — حجز البايتات تحت قفل
**الحالة:** مقبول، **يحكمه الاختبار**. (Codex اقترح pause/ack؛ المعماري حجز تحت قفل.)
**القرار:** لكل جزء `{start,pos,end}` خلف قفل صغير. العامل **يحجز** `n=min(buf,end-pos)` تحت القفل ثم يكتب ويُسجّل الإنجاز؛ المنسّق يقصّ `end` إلى `mid=max(pos,(pos+end)/2)` تحت نفس القفل ويسلّم `[mid,end)` لعامل جديد. الحجز لا يُقصّ أبداً ⇒ لا بايت مفقود ولا مكرر دون حاجة لحوار توقف/إقرار.
**معيار التحكيم:** اختبار عشوائي (≥ 200 بذرة، نقاط yield عشوائية داخل الحجز والكتابة والتقصير، أحجام أجزاء وسرعات عشوائية، أخطاء شبكة محقونة) يتحقق من: تغطية كاملة بلا فجوات/تداخل، تطابق SHA-256، لا كتابة خارج النطاق. إن فشل أي بذرة نعتمد pause/ack.
