# ADR-0001: الواجهة Tauri 2 + Svelte 5 (وليس Slint)
**الحالة:** مقبول. **التاريخ:** 2026-11-13.

**السياق:** عربي RTL صحيح وخفيف (رسمة المستخدم: «الواجهة العربية: Tauri + Svelte»). ويندوز 10 قد يفتقد WebView2.
**الخيارات:** Tauri+Svelte · Slint (يستخدمه Ezoo) · Electron · egui/iced.
**القرار:** Tauri 2 + Svelte 5 + TypeScript. محرك الويب يطبّق BiDi وتشكيل الحروف و`dir=rtl` وخصائص CSS المنطقية فتنعكس الواجهة كلها؛ أسماء الملفات والروابط تُعزل بـ`<bdi>`. Slint: الشكل ممكن لكن عكس الواجهة والنص المختلط أضعف. Electron: ثقيل. egui/iced: العربية ضعيفة.
**العواقب:** لا يمكن بناء/تشغيل نافذة Tauri على صندوق Linux هنا (لا webkit2gtk/root) ⇒ الواجهة تتكلم عبر `api.ts` ذي تنفيذ وهمي للمتصفح، ولقطات الشاشة من Chrome headless؛ النافذة الحقيقية تُختبر في CI على Windows فقط. جزء Rust في `src-tauri` رقيق جداً، ولا تعتمد crates المحرك على Tauri.
**الدليل المطلوب:** لقطات ar/en × فاتح/داكن؛ اختبار مفاتيح الترجمة؛ اختبار فحص RTL لنص مختلط (P5). مراقب في CI: بناء Tauri على windows-latest.
