# ADR-0004: حالة المهام JSON ذري لكل مهمة
**الحالة:** مقبول للإصدار الأول (Codex فضّل SQLite).
**السياق:** لا مترجم C في بناء msvc المتقاطع هنا؛ المهام النشطة قليلة.
**القرار:** `jobs/<id>.json` + `queues.json` + `settings.json`. كاتب واحد؛ نقطة حفظ كل 2–5 ث للمهام النشطة فقط؛ الترتيب: تثبيت البايتات (`sync_data`) ثم تسلسل الإزاحات ثم ملف مؤقت فريد في نفس المجلد ثم `fsync` ثم استبدال ذري (ReplaceFileW مع `.bak` على Windows، rename على Unix) مع إعادة محاولة محدودة عند تعارض مضاد الفيروسات؛ تحقق من المخطط والتغطية عند التحميل؛ الملف الفاسد يُعزل `.broken` ويُستعاد `.bak`. الملف يُنشأ بصلاحيات المستخدم وحده. لا كلمات سر ولا كوكيز فيه؛ يُحذف `user:pass@` من الروابط.
**العواقب:** >20 ألف مهمة نشطة غير مدعوم؛ نراجع SQLite لاحقاً.
**الدليل:** اختبارات P1: ملف تالف/مقتطع/بمسار خبيث مرفوض؛ قتل العملية أثناء الحفظ؛ البحث عن السر في الملف المكتوب نفسه؛ اختبار الأذونات.
