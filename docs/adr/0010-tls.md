# ADR-0010: TLS — SChannel على ويندوز، rustls غيره
**الحالة:** مقبول. **السبب:** يستخدم مخزن شهادات ويندوز (شركات/مضادات فيروسات)، ALPN، ولا يحتاج مترجم C. **الدليل (تجربة 2026-11-13):** `reqwest` بميزة `native-tls-alpn` لـWindows وrustls لغيره بُني بنجاح بـ`cargo zigbuild --target x86_64-pc-windows-gnu` و`cargo xwin build --target x86_64-pc-windows-msvc`؛ rustls/ring وحده فشل على msvc (يحتاج `clang-cl`). **قاعدة:** لا تعطيل للتحقق من الشهادات أبداً؛ اختبارات TLS تستخدم جذراً محلياً داخل `#[cfg(test)]`/ميزة `test-support` فقط، وكل اختبار رفض معه اختبار نجاح.
