# ADR-0007: موافقة المستخدم قبل أدوات الفيديو
**الحالة:** مقبول (رسمة المستخدم: «الفيديو، بموافقتك»؛ زاجل تفعل الشيء نفسه — ADR-0009 عندهم).
**القرار:** لا تنزيل ولا تشغيل لـyt-dlp/FFmpeg/JS runtime قبل نافذة موافقة (عربي/إنجليزي) تذكر الأدوات وإصداراتها ومصدرها الرسمي والتحقق بـSHA-256 ومسؤولية المستخدم عن الحقوق، ورفض DRM. تُخزَّن الموافقة (نسخة النص + وقت) ويمكن سحبها (تحذف الأدوات). CLI: يسأل مرة، أو `--yes`. إضافة المتصفح لا تعرض زر الفيديو قبل الموافقة. الأدوات **تُنزَّل فقط** من الإصدار الرسمي بعد الموافقة (لا نعيد توزيعها داخل مثبّتنا، فلا التزامات إعادة توزيع GPL/LGPL علينا) وتُثبَّت بإصدار وبصمة؛ تُفحص البصمة قبل كل تشغيل؛ لا تحديث صامت.
**الدليل:** P4: اختبار أن `eid video` بدون موافقة لا يشغّل شيئاً ولا يتصل بالشبكة؛ اختبار فشل بصمة خاطئة؛ اختبار عدم تنفيذ أداة من PATH.
