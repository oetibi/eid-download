## السبب الجذري لغياب الزر في Firefox (مثبت)
`content.js` كان يقرأ المنطق المشترك من `window.EidCore`. في Firefox متغيّرات سكربت المحتوى في صندوق منفصل و`window` غلاف لنافذة الصفحة، فكان غير معرَّف والسكربت يخرج بصمت في كل صفحة. الدليل: run 44717375680 (قبل) لا زر ولا طلب؛ run 44717763588 (صلاحيات المواقع فقط) لا زر؛ run 44718053772 (الإصلاح) نجح. التفاصيل في `docs/STATUS.md`.

## حدود معروفة
- **Firefox:** التثبيت الدائم يحتاج توقيع Mozilla (AMO)؛ المختبر هو التثبيت المؤقت (يزول عند إغلاق Firefox).
- **Chrome/Edge/Brave/Opera:** الإضافة غير منشورة في المتاجر؛ التثبيت «غير مضغوط» من وضع المطوّر.
- **ملء الشاشة، لوحة المفاتيح، المظهر بالعربية، استهلاك المعالج:** لم تُختبر آلياً.
- **Linux/macOS:** المنتج لـWindows؛ تسجيل Brave/Opera/Vivaldi على Linux لم يُفحص.
- **مواقع غير يوتيوب:** الزر لملف فيديو HTML5 مباشر فقط؛ لا DRM/EME، ولا blob/MSE خارج يوتيوب، ولا تجاوز تسجيل دخول أو حماية.
