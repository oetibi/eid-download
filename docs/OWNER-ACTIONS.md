# خطوات المالك (v0.1.2) — كل ما لا تستطيع الأتمتة فعله نيابةً عنك

كل خطوة هنا محضّرة بالكامل: الأوامر، الملفات، وما يجب أن تراه. إن فشل شيء، أرسل لقطة الشاشة
ومحتوى الملف المذكور في الخطوة. **لا شيء هنا يحذف بياناتك.**

الترتيب المقترح: (1) تثبيت والتجربة اليدوية ← (2) الإضافة في المتصفحات ← (3) مقارنة IDM ←
(4) قرار تحويل الإصدار إلى «نهائي» ← (5) المتاجر ← (6) التوقيع الرقمي.

---

## 1) تجربة البرنامج على جهازك (Windows 10/11) — ~20 دقيقة

1. من صفحة الإصدار التجريبي `v0.1.2` (https://github.com/oetibi/eid-download/releases/tag/v0.1.2) نزّل `EidDownload-0.1.2-windows-x64-setup.exe` و`SHA256SUMS.txt`.
2. تحقق من البصمة في PowerShell:
   ```powershell
   Get-FileHash .\EidDownload-0.1.2-windows-x64-setup.exe -Algorithm SHA256
   ```
   يجب أن تطابق السطر نفسه في `SHA256SUMS.txt`.
3. ثبّت (لا يحتاج صلاحيات مدير؛ SmartScreen: More info ← Run anyway، لأن الملف غير موقّع بعد — انظر 6).
4. قائمة الفحص (ضع ✔ أو ✘ مع لقطة):

| # | الخطوة | المتوقع |
|---|---|---|
| 1 | افتح البرنامج | يفتح خلال ثانية-ثانيتين، بالعربية ومن اليمين لليسار |
| 2 | «إضافة تحميل» ← رابط ملف كبير (مثلاً ISO لـUbuntu) | يبدأ، السرعة والوقت المتبقي يتحركان بسلاسة |
| 3 | إيقاف مؤقت ← أغلق البرنامج ← افتحه ← استكمال | يكمل من حيث توقف ولا يبدأ من الصفر |
| 4 | الإعدادات ← التحميلات: الاتصالات 16، حد السرعة 1024، التحميلات في نفس الوقت 2 ← حفظ | يظهر «تم الحفظ»؛ السرعة الكلية تنزل لنحو 1 م.ب/ث فوراً |
| 5 | أرجع حد السرعة 0 ← حفظ | ترجع السرعة الكاملة |
| 6 | المجدول: فعّله، من الآن+2 دقيقة إلى الآن+10، اليوم الحالي ← حفظ، ثم أضف تحميلاً | ينتظر التحميل ثم يبدأ وحده في الوقت المحدد |
| 7 | عطّل المجدول ← حفظ | التحميلات تعمل فوراً |
| 8 | تحميل مكتمل ← «فتح الملف» | يفتح بالبرنامج الافتراضي |
| 9 | حمّل أي ملف `.exe` ← «فتح الملف» | **لا يُشغَّل**؛ رسالة واضحة ويُفتح المجلد بدلاً منه |
| 10 | «تحميل فيديو» ← رابط يوتيوب | أول مرة: نافذة موافقة بنص كامل؛ الزر معطّل حتى تضع ✔؛ بعدها تنزل الأدوات |
| 11 | فيديو واحد بجودة 1080p | ملف بصوت وصورة، الدقة الصحيحة |
| 12 | «صوت فقط» | ملف mp3 |
| 13 | رابط قائمة تشغيل ← اختر 3 عناصر ← جودة 720p | مجلد باسم القائمة، ملفات مرقّمة `001 - …` |
| 14 | أوقف القائمة مؤقتاً أثناء التحميل ← استكمال | يكمل؛ العناصر المكتملة لا تُعاد |
| 15 | أعد نفس القائمة مرة ثانية | لا يُعاد تحميل شيء مكتمل |
| 16 | بدّل اللغة إلى English والسمة إلى داكنة | كل النصوص تتغير، لا نص مقطوع |
| 17 | 3 تحميلات معاً + تصفح القائمة | لا تجمّد ولا تقطيع في الواجهة |
| 18 | مدير المهام: ذاكرة `EidDownload.exe` + `msedgewebview2.exe` وهو خامل | سجّل الرقم (للمقارنة مع أرقام CI في `docs/BENCHMARKS.md`) |
| 19 | أزل التثبيت من «التطبيقات» (بلا ✔ على حذف البيانات) | يُزال البرنامج؛ قائمتك وإعداداتك تبقى لإعادة التثبيت |

## 2) إضافة المتصفح (Chrome / Edge / Firefox) — ~15 دقيقة

المثبّت يسجّل اتصال المتصفح (Native Messaging) تلقائياً لـChrome وEdge وFirefox بالمعرّفات الموجودة
في `extension/native-host-ids.json`. حتى تُنشر الإضافة في المتاجر (الخطوة 5) ثبّتها يدوياً:

1. من صفحة الإصدار نزّل `eid-download-chrome-sideload-0.1.2.zip` (لـChrome وEdge) و`eid-download-firefox-0.1.2.zip`
   وفك ضغط كل واحد في مجلد ثابت (لا تحذفه بعد التثبيت).
   **مهم:** للتثبيت اليدوي استخدم ملف `sideload` تحديداً: فيه المفتاح العام الذي يثبّت المعرّف
   `ambokeecedpgicighhcpdfjphdnphgaa` المسجّل في المثبّت. ملف المتجر `eid-download-chrome-0.1.2.zip`
   بلا مفتاح (المتاجر ترفضه) فيأخذ معرّفاً آخر لن يقبله البرنامج قبل الخطوة 5.
2. Chrome: `chrome://extensions` ← وضع المطوّر ← Load unpacked ← المجلد. Edge: `edge://extensions` بنفس الطريقة.
   Firefox: `about:debugging#/runtime/this-firefox` ← Load Temporary Add-on ← `manifest.json`.
3. قائمة الفحص في كل متصفح:

| # | الخطوة | المتوقع |
|---|---|---|
| 1 | افتح فيديو يوتيوب | زر «تحميل هذا الفيديو» فوق المشغّل عند مرور الفأرة |
| 2 | اضغط الزر | قائمة الجودات (حتى 4K، لا 8K) + «صوت فقط» |
| 3 | اختر 720p | «أُرسل إلى Eid Download» ويظهر التحميل في البرنامج |
| 4 | صفحة فيديو داخل قائمة تشغيل (`&list=`) ← الزر | قسم «قائمة التشغيل» بعدد العناصر، «تنزيل القائمة كاملة» و«اختيار عناصر…» |
| 5 | «اختيار عناصر…» ← عنصران ← تنزيل | مهمة قائمة بعنصرين في البرنامج |
| 6 | فيديو صغير (أقل من 200×120، مثلاً معاينة مصغرة) | لا يظهر الزر |
| 7 | Netflix أو أي فيديو محمي DRM | رسالة «هذا الفيديو محمي» — لا تحميل (عمداً) |
| 8 | أغلق البرنامج ثم اضغط الزر | يُشغَّل البرنامج أو رسالة واضحة |
| 9 | إعدادات الإضافة: الموضع/الحجم/اللون/المواقع المستثناة | تتغير فوراً على الصفحة |

ما اختُبر آلياً بالفعل (انظر `docs/EXTENSION.md`): الإضافة في Chrome حقيقي ← مضيف حقيقي ← البرنامج ←
yt-dlp حقيقي ← ملف فيديو حقيقي. **ما لم يُختبر آلياً:** الزر على صفحة يوتيوب الحقيقية (يوتيوب يحجب
المتصفح الآلي)، وEdge وFirefox يدوياً على Windows.

## 3) مقارنة السرعة مع IDM على جهازك — ~15 دقيقة

السكربت `scripts/windows/compare_idm.ps1` يشغّل Eid وIDM بالتناوب على **نفس الملف ونفس الخادم**
ويقيس الوقت ويتحقق من بصمة SHA-256 لكل ملف. لا يغيّر أي إعداد في IDM.

1. ثبّت أدوات البناء مرة واحدة: Rust (`winget install Rustlang.Rustup`) وGit.
2. ```powershell
   git clone https://github.com/oetibi/eid-download; cd eid-download
   cargo build --release -p eid-cli -p eid-testserver
   ```
3. في IDM: Options ← Connection ← «Default max. conn. number» = 8، وألغِ أي حد سرعة.
4. اختبار محلي (خادم يحدّ كل اتصال بـ4 م.ب/ث — الحالة التي يفيد فيها تعدد الاتصالات):
   ```powershell
   scripts\windows\compare_idm.ps1 -Connections 8,16 -Runs 3
   ```
   السكربت يطلب منك تغيير عدد اتصالات IDM إلى 16 قبل الجولة الثانية.
5. اختبار على الإنترنت بملف كبير حقيقي:
   ```powershell
   scripts\windows\compare_idm.ps1 -Url "https://releases.ubuntu.com/24.04/ubuntu-24.04.3-desktop-amd64.iso" -Connections 8 -Runs 3
   ```
6. أرسل `idm-compare\results.json`. سأضيفه إلى `docs/BENCHMARKS.md` كما هو.

## 5) نشر الإضافة في المتاجر (يحتاج حساباتك)

الحزم جاهزة في صفحة الإصدار وتُبنى بـ`node scripts/ext/package.mjs` (نفس المصدر = نفس البايتات):
`eid-download-chrome-0.1.2.zip` (Chrome Web Store **و** Edge Add-ons) و`eid-download-firefox-0.1.2.zip` (AMO).
لا ترفع ملف `sideload` إلى أي متجر.

| المتجر | الحساب | الرسوم | الرابط |
|---|---|---|---|
| Chrome Web Store | حساب مطوّر Google | رسوم تسجيل لمرة واحدة (يحددها Google) | https://chrome.google.com/webstore/devconsole |
| Microsoft Edge Add-ons | Partner Center | مجاني | https://partner.microsoft.com/dashboard/microsoftedge |
| Firefox (AMO) | حساب Mozilla | مجاني | https://addons.mozilla.org/developers/ |

**الرسوم والحسابات قرارك؛ لم أنشئ أي حساب ولم أدفع شيئاً.**

نص القائمة (انسخه كما هو):

- **الاسم:** Eid Download
- **ملخص (EN):** Adds a "Download this video" button over video players that sends the page to the Eid Download desktop app for Windows.
- **ملخص (AR):** يضيف زر «تحميل هذا الفيديو» فوق مشغّلات الفيديو ويرسل الصفحة إلى برنامج Eid Download على Windows.
- **الوصف (EN):** Eid Download for Windows downloads files with up to 32 connections, resumes after restarts, and downloads videos and playlists through yt-dlp. This extension puts a button over video players: pick a quality (up to 4K) or audio only, or choose items from a playlist, and the desktop app does the download. Requires the Eid Download app (https://github.com/oetibi/eid-download/releases). It does not download DRM-protected media.
- **الوصف (AR):** برنامج Eid Download لـWindows يحمّل الملفات بما يصل إلى 32 اتصالاً، ويكمل بعد إعادة التشغيل، ويحمّل الفيديو وقوائم التشغيل عبر yt-dlp. هذه الإضافة تضع زراً فوق مشغّل الفيديو: اختر الجودة (حتى 4K) أو الصوت فقط، أو اختر عناصر من قائمة تشغيل، والبرنامج يتولى التحميل. تتطلب برنامج Eid Download. لا تحمّل المحتوى المحمي بـDRM.
- **الفئة:** Productivity (Chrome/Edge)، Download Management (Firefox).
- **تبرير الصلاحيات:** `nativeMessaging`: لإرسال رابط الصفحة إلى البرنامج المثبّت على الجهاز. `storage`: لحفظ إعدادات الزر (الموضع والحجم واللون والمواقع المستثناة). الوصول إلى المواقع: لإظهار الزر فوق مشغّلات الفيديو في أي موقع؛ لا يُقرأ ولا يُرسل أي شيء حتى يضغط المستخدم خياراً.
- **جمع البيانات:** لا شيء. (Firefox: `data_collection_permissions: none` موجود في الحزمة.)
- **سياسة الخصوصية:** استخدم `docs/PRIVACY.md` (رابطه على GitHub).
- **لقطات الشاشة:** المتاجر تطلب لقطات 1280×800: صوّرها أثناء التجربة (2) — الزر فوق الفيديو، والقائمة، واختيار عناصر القائمة.

بعد النشر: كل متجر يعطي معرّفاً للإضافة. **Chrome/Edge**: أضف المعرّف إلى القائمتين `chrome` و`edge`
في `extension/native-host-ids.json` (لا تحذف المعرّف الحالي، فهو للتثبيت اليدوي)، ثم إصدار جديد
ليسجّله المثبّت. **Firefox**: المعرّف `eid-download@eid-download` نفسه، لا تغيير. أو أرسل لي المعرّفات وأنا أضيفها.

## 6) التوقيع الرقمي (يزيل تحذير SmartScreen) — يحتاج شراء/تسجيل منك

الخيارات (كلها مدفوعة أو تحتاج تحقق هوية؛ **لم أشترِ ولم أسجّل شيئاً**):
1. **Azure Trusted Signing** (اشتراك شهري منخفض، يحتاج تحقق هوية): الأنسب لـGitHub Actions.
2. **شهادة OV/EV** من جهة إصدار (سنوية).
3. **SignPath.io** (مجاني للمشاريع مفتوحة المصدر بعد قبول طلب).

بعد اختيارك أحتاج: نوع الخدمة، واسم الشهادة، وأن تضيف الأسرار في GitHub ← Settings ← Secrets
(لا ترسلها لي في المحادثة). عندها أضيف خطوة التوقيع إلى `ci-windows.yml` قبل حساب البصمات،
لـ`EidDownload.exe` و`eid.exe` و`eid-native-host.exe` والمثبّت.

## ملاحظة عن أرقام الإصدارات
`v0.1.0` و`v0.1.1` وسمان بلا إصدار: بُنيا واجتازا كل اختبارات Windows لكن خطوة النشر الأخيرة فشلت
(CRLF في ملف البصمات، ثم أمر اختبارات الإضافة). لم يُحذفا. منذ PR «release dry run» تُجرَّب خطوة النشر
كاملة في كل PR قبل أي وسم، ويمكن تجربتها محلياً: `python3 scripts/ci/simulate_release.py --artifact DIR`.
**الإصدار التالي:** ارفع الرقم في `Cargo.toml` و`crates/eid-gui/tauri.conf.json` و`scripts/ext/build.mjs`
(و`cargo update -w`)، أضف `docs/releases/vX.Y.Z.md`، وانتظر dry run أخضر في PR قبل الوسم.
