# تجربة إصلاحات Windows (فرع `fix/windows-real-usage`) — خطوات المالك

هذه الخطوات للمشاكل الخمس التي وجدتها على Windows حقيقي (2026-11-19). كل بند مكتوب بجانبه ما اختُبر آلياً وما لم يُختبر.

**الملف:** artifact باسم `eid-windows-x64` من آخر تشغيل ناجح لـci-windows على الفرع `fix/windows-real-usage` (صفحة Actions ← التشغيل ← أسفل الصفحة «Artifacts»). داخله:
- `dist/EidDownload-windows-x64.zip` (نسخة محمولة)
- `dist/EidDownload-<الرقم>-windows-x64-setup.exe` (المثبّت)
- `dist/ext/*.zip` (حزم الإضافة)
- `crates/eid-gui/INSTALL-BROWSER-EXTENSION.txt`
- `SHA256SUMS.txt`

قارن البصمة قبل التشغيل: `Get-FileHash <الملف> -Algorithm SHA256`. البرنامج غير موقّع: SmartScreen ← «More info» ← «Run anyway».

## 0) النسخة المحمولة: فك الضغط أولاً (هذا سبب الخطأ os error 2)
- [ ] **جرّب الخطأ القديم عمداً:** افتح ملف ZIP في Explorer وانقر EidDownload.exe مرتين من داخله دون فك الضغط. **المتوقع الآن:** شريط برتقالي أسفل النافذة يقول إنك فتحت البرنامج من داخل ZIP، ويذكر أن eid-native-host.exe غير موجود. الفيديو وتنزيل الأدوات **يعملان** رغم ذلك (لم تعد تحتاج eid.exe).
- [ ] أغلقه. انقر بالزر الأيمن على ملف ZIP ← «استخراج الكل»، وشغّل EidDownload.exe من المجلد المستخرج: **لا يظهر الشريط**.

## 1) الفيديو وتنزيل الأدوات (المشكلتان 1 و2)
- [ ] «فيديو» ← رابط يوتيوب ← «فحص»: يظهر طلب تنزيل الأدوات (لا os error 2).
- [ ] «تنزيل الأدوات» ← اقرأ الموافقة ← ضع علامة ← «تثبيت». انتظر حتى يختفي مربع «الأدوات غير موجودة» (التنزيل نحو 230 MB: yt-dlp وFFmpeg وDeno، مع فحص SHA-256 لكل ملف).
- [ ] افحص الرابط من جديد: تظهر الجودات. اختر 720p ← «ابدأ». يكتمل الملف في مجلد التنزيلات ويعمل.
- [ ] إن فشل: أرسل لي نص الرسالة كما هو. الرسائل الآن تسمّي الملف الناقص وما يجب فعله.

## 2) رابط يوتيوب في «إضافة» (المشكلة 3)
- [ ] «إضافة» ← الصق رابط يوتيوب (`watch?v=` أو `youtu.be/` أو `shorts/`) ← «ابدأ». **المتوقع:** لا يُضاف ملف؛ تُفتح نافذة «فيديو» بالرابط مع رسالة «هذا رابط صفحة فيديو».
- [ ] «إضافة» ← رابط صفحة ويب عادية ليست ملفاً (مثلاً `https://example.com/`). **المتوقع:** يفشل فوراً برسالة «الرابط يفتح صفحة ويب لا ملفاً، فلم يُحفظ شيء»، ولا يُكتب أي ملف.
- [ ] Ctrl+V في النافذة بعد نسخ رابط يوتيوب: تُفتح نافذة «فيديو».

## 3) إضافة المتصفح (المشكلة 4) — التفاصيل في INSTALL-BROWSER-EXTENSION.txt
- [ ] **النسخة المحمولة:** الإعدادات ← «سطح المكتب» ← «إضافة المتصفح» ← «ربط المتصفحات بهذه النسخة». يجب أن يظهر Chrome وEdge وFirefox: «مربوط بهذه النسخة».
- [ ] **المثبّت:** بعد التثبيت، نفس المكان يقول «مربوط بهذه النسخة» دون ضغط أي زر.
- [ ] Chrome أو Edge: `chrome://extensions` (أو `edge://extensions`) ← «وضع المطوّر» ← «تحميل إضافة غير مضغوطة» ← المجلد `browser-extension\chrome-edge` بجانب البرنامج. رقم الإضافة يجب أن يكون `ambokeecedpgicighhcpdfjphdnphgaa`. أعد تشغيل المتصفح.
- [ ] Firefox: `about:debugging#/runtime/this-firefox` ← «تحميل إضافة مؤقتة» ← `browser-extension\firefox\manifest.json`. **مؤقتة:** تُزال عند إغلاق Firefox.
- [ ] في كل متصفح: خيارات الإضافة ← «اختبار الاتصال» ← «Eid Download استجاب». ثم صفحة فيديو: يظهر زر Eid فوق الفيديو.

**يحتاج قرارك أو حسابك (لم أفعله):**
- **Firefox دائم:** يحتاج توقيع Mozilla. ارفع `eid-download-firefox-<v>.zip` إلى addons.mozilla.org من حسابك، كنشر «غير مدرج» (unlisted) للتوزيع الذاتي. ثم أضيف ملف ‎.xpi‎ الموقّع إلى الحزمة.
- **Chrome Web Store وEdge Add-ons:** حساب مطوّر لكل متجر. ستعطي المتاجر أرقاماً جديدة للإضافة، ويجب إضافتها إلى `extension/native-host-ids.json`.

## 4) الملفات العادية (المشكلة 5)
- [ ] «إضافة» ← رابط ملف كبير حقيقي ← «ابدأ»: يظهر التقدم والسرعة، ثم «مكتمل». انقر بالزر الأيمن ← «فتح الملف» و«إظهار في المجلد».
- [ ] أثناء تحميل: حدده ← «إيقاف» في شريط الأدوات ← «استكمال»: يكمل من حيث توقف.
- [ ] أغلق البرنامج أثناء تحميل وافتحه: يستكمل، والملف سليم.
- [ ] إن بقيت مشكلة في الملفات العادية: **صِف الخطوة بالضبط والرسالة**. لم أجد في وصفك خطأً محدداً غير مشكلة يوتيوب و«من داخل ZIP»، وكل المسار مختبر آلياً على Windows (أدناه).

## ما اختُبر آلياً على Windows (CI) وما لم يُختبر
- **مختبر على النافذة الحقيقية** (`scripts/windows/window_e2e.mjs` في ci-windows). الاختبار ينقر أزرار نافذة WebView2 الحقيقية:
  - البرنامج وحده في مجلد `Temp1_<zip>.zip`.
  - ملف حقيقي يُحمَّل ويُطابَق بـSHA-256.
  - يوتيوب يفتح نافذة الفيديو، والفحص يعمل.
  - صفحة الويب تُرفض.
  - إيقاف واستكمال من شريط الأدوات مع SHA-256.
  - رفض الربط من داخل ZIP.
  - نسخة مستخرجة: الربط ومفاتيح HKCU، و`eid-native-host.exe` يجيب كما يجيب للمتصفح، وإلغاء الربط.
- **مختبر بالإنترنت الحقيقي** (`real-video.yml`، مهمة `window`، يدوي): تثبيت الأدوات من النافذة بعد الموافقة، وتحميل فيديو PeerTube حقيقي بجودة 360p من النافذة.
- **لم يُختبر:**
  - تثبيت الإضافة فعلياً في Chrome وEdge وFirefox على Windows. الإضافة نفسها مختبرة في Chrome على Linux.
  - يوتيوب الحقيقي من مشغّلات GitHub، لأن يوتيوب يطلب التحقق من أنها ليست روبوتاً.
  - «فتح الملف» بنقرة حقيقية.

## أرسل لي
القائمة بعلاماتها، ولقطات ما فشل، ونص أي رسالة خطأ كما هو، ونسخة Windows.
