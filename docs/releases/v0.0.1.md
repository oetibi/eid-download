# Eid Download v0.0.1 — نسخة تجريبية أولى لـWindows x64

**نسخة تجريبية (pre-release)، غير موقّعة رقمياً.** بُنيت في GitHub Actions من هذا الوسم فقط، بعد نجاح اختبارات Windows وفحص الواجهة الآلي (GUI smoke) على نفس الملفات المرفقة.

## التشغيل
1. نزّل `EidDownload-windows-x64.zip` وفك ضغطه.
2. اضغط مرتين على `EidDownload.exe`. إن ظهر SmartScreen: More info ← Run anyway.
3. «إضافة تحميل» ← الصق الرابط ← «ابدأ التحميل».

يحتاج Microsoft Edge WebView2 (موجود في Windows 11 ومعظم أجهزة Windows 10 المحدّثة).

## ما فيه (حالة كل بند)
- إضافة روابط وتحميلها مع التقدم والسرعة والوقت المتبقي، إيقاف مؤقت واستكمال، إعادة محاولة، إزالة من القائمة، حفظ القائمة واستكمالها بعد إعادة التشغيل — **مختبرة** (اختبارات `eid-gui` و`eid-engine` وفحص `scripts/gui_smoke.ps1` في CI: تحميل حقيقي من الخادم المحلي ومطابقة SHA-256).
- تشغيل ثانٍ للبرنامج يُظهر النافذة المفتوحة ويخرج — **مختبر** (`show_wakes_the_window_and_everything_else_goes_to_the_shared_handler`، الخطوة 4 في gui_smoke).
- رسالة واضحة عند غياب WebView2 مع حفظ القائمة — **مختبر** (الخطوة 9 في gui_smoke، بمحاكاة غياب WebView2).
- سطر الأوامر `eid.exe` يتحكم بالنافذة المفتوحة — **مختبر** (gui_smoke).
- تحميل الفيديو (yt-dlp) — موجود في `eid.exe` فقط، **ليس في الواجهة بعد**.
- إضافة المتصفح — **مخطط** (`eid-native-host.exe` مرفق لكنها لم تُنشر).

## لم يُختبر يدوياً
- تشغيل البرنامج يدوياً بالفأرة على جهاز مستخدم حقيقي (الفحص آلي على Windows Server في CI).
- Windows 11، والشاشات عالية الدقة، واللغة العربية في نظام بإعدادات مختلفة.
- نافذة اختيار المجلد و«إظهار في المجلد» (لا تُفحص آلياً).
- جهاز بلا WebView2 فعلاً (فُحص بالمحاكاة فقط).
- تحميلات كبيرة من خوادم إنترنت حقيقية (الاختبارات على خادم محلي).
