# تجربة نسخة PR #7 على Windows (قبل v0.2.0-beta) — خطوات المالك

**الملف:** artifact باسم `eid-windows-x64` من آخر تشغيل ناجح لـci-windows على PR #7 (صفحة Actions، أسفل صفحة التشغيل، قسم Artifacts؛ يحتاج تسجيل الدخول إلى GitHub). داخله:
`dist/EidDownload-<الرقم>-windows-x64-setup.exe` (المثبّت) و`dist/EidDownload-windows-x64.zip` (نسخة محمولة) و`SHA256SUMS.txt`.
**ملاحظة:** الرقم داخل الملف ما زال `0.1.2` لأن رفع الرقم إلى `0.2.0-beta` يحدث عند الإصدار فقط (بقرارك). المثبّت غير موقّع: SmartScreen ← «More info» ← «Run anyway».

## 0) قبل التثبيت (دقيقتان)
1. فك ضغط الـartifact في مجلد جديد.
2. PowerShell في ذلك المجلد:
   `Get-FileHash .\dist\EidDownload-*-setup.exe -Algorithm SHA256` وقارن الناتج بالسطر المقابل في `SHA256SUMS.txt`.
3. (اختياري) إن أردت إبقاء نسختك الحالية سليمة: جرّب النسخة المحمولة (ZIP) بدل المثبّت.

## 1) الواجهة (10 دقائق) — ضع ✔ أو ✘ ولقطة عند الخطأ
- [ ] تُفتح النافذة بالعربية من اليمين لليسار؛ «English» في الأعلى يحوّلها.
- [ ] شريط الأدوات: إضافة، فيديو، استكمال، إيقاف، إيقاف الكل، إزالة، مسح المكتملة، المجدول، الإعدادات، وخانة البحث.
- [ ] زر الفأرة الأيمن على شريط الأدوات ← «تخصيص شريط الأدوات»: أخفِ زراً، وجرّب «أيقونات فقط».
- [ ] زر الفأرة الأيمن على عناوين الأعمدة ← أخفِ عموداً؛ اسحب عنوان عمود لمكان آخر؛ اسحب حافته لتغيير العرض؛ أغلق البرنامج وافتحه: يبقى كما تركته.
- [ ] Ctrl+F ثم اكتب جزءاً من اسم ملف: تظهر الصفوف المطابقة فقط؛ Esc يعيد الكل.
- [ ] الوضع الداكن/الفاتح من «عرض».

## 2) التحميلات (10 دقائق)
- [ ] «إضافة» ← رابط ملف كبير حقيقي (مثلاً صورة ISO لتوزيعة Linux) ← ابدأ. يظهر التقدم والسرعة والوقت المتبقي.
- [ ] اسحب رابطاً من المتصفح وأفلته على النافذة: تُفتح نافذة الإضافة بالرابط.
- [ ] انقر مرتين على التحميل ← «خريطة الأجزاء» تمتلئ أثناء التحميل (تتحدث كل ثانيتين تقريباً)، والجدول يعرض الأجزاء.
- [ ] في نفس النافذة: «حد سرعة هذا التحميل» = 500 ← تطبيق: تنخفض السرعة إلى نحو 500 ك.ب/ث ويستكمل التحميل؛ ضع 0 ← تعود السرعة.
- [ ] أغلق البرنامج أثناء التحميل وافتحه: يستكمل من حيث توقف، والملف النهائي سليم.
- [ ] «التحميلات ← قوائم الانتظار…»: غيّر «عدد التحميلات معاً»، وجرّب «إيقاف القائمة» ثم «تشغيل القائمة».
- [ ] عند اكتمال تحميل أو فشله تظهر رسالة صغيرة أسفل النافذة.

## 3) سطح المكتب (5 دقائق)
- [ ] أيقونة Eid Download بجانب الساعة: النقر يُظهر النافذة؛ القائمة: إظهار/إيقاف الكل/استكمال الكل/خروج (بلغة النافذة).
- [ ] الإعدادات ← عام ← «إغلاق النافذة يخفيها…»: فعّله ثم أغلق النافذة: يبقى البرنامج في الأيقونة؛ «خروج» من الأيقونة يغلقه.
- [ ] الإعدادات ← «مراقبة الحافظة» (معطلة افتراضياً): فعّلها ثم انسخ رابط ملف .zip من المتصفح: يظهر شريط «رابط منسوخ» مع «تحميل/تجاهل». انسخ نصاً عادياً: لا يظهر شيء.

## 4) الفيديو وقوائم التشغيل (5 دقائق، يحتاج الموافقة على تنزيل الأدوات أول مرة)
- [ ] «فيديو» ← رابط فيديو يوتيوب ← فحص ← تظهر الجودات المتاحة فقط (لا 8K) ← ابدأ.
- [ ] رابط قائمة تشغيل ← اختر بعض المقاطع ← جودة 1080p ← «إن لم تتوفر هذه الجودة»: جرّب «تخطَّ المقطع».

## 5) لا تجرّبه إلا إذا أردت
- **إيقاف التشغيل/السكون/الإسبات:** معطلة افتراضياً (الإعدادات ← «السماح بسكون الجهاز…»). إن فعّلتها واخترت «إيقاف تشغيل الجهاز» لقائمة، فبعد انتهاء تحميلاتها يظهر شريط عدّ تنازلي 60 ثانية مع «إلغاء». **احفظ عملك قبل التجربة.** لم أجرّب الإطفاء الفعلي في أي اختبار (قرارك).

## أرسل لي
القائمة بعلاماتها، ولقطات ما فشل، ونسخة Windows (10 أو 11). سأسجلها في `docs/STATUS.md` كما هي.
