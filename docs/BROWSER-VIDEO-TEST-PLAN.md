# خطة اختبار: الإضافة في المتصفحات، قائمة التحميل، قوائم التشغيل (طلب المالك 2026-11-20)

كل بند: ما يثبته آلياً (اسم الاختبار أو الفحص ومكان تشغيله)، وما بقي يدوياً. **الصفحات في الاختبارات الآلية بديلة**: تُقدَّم عند `www.youtube.com` باعتراض طلبات المتصفح نفسه، ولا يذهب شيء إلى يوتيوب. والمضيف في اختبار المتصفحات بديل (`scripts/ext/stub-host.mjs`) يجيب كما يجيب التطبيق ويسجّل ما وصله. لذلك لا يثبت أي اختبار هنا أن يوتيوب الحقيقي يعمل.

## 1. المتصفحات وتثبيت الإضافة
| المتصفح | آلي | أين | يدوي |
|---|---|---|---|
| Firefox | `browser_e2e.mjs --browser firefox` (8 فحوص)، تثبيت مؤقت كما في `about:debugging` | ci-windows، مهمة `browsers (firefox)` | التثبيت المؤقت على جهاز المالك (Firefox 160)؛ التثبيت الدائم يحتاج توقيع AMO (لم يُفعل) |
| Chrome | `browser_e2e.mjs --browser chrome` | ci-windows + محلياً على Linux | «تحميل إضافة غير مضغوطة» على جهاز المالك |
| Edge | `browser_e2e.mjs --browser edge` | ci-windows | نفسه |
| Brave، Opera، Vivaldi | `scripts/ext/more_browsers.ps1`: يثبّت المتصفح على المشغّل، ويجرّب مفاتيح Native Messaging المرشّحة كلاً وحده، ثم الفحوص كلها بالمفتاح الذي وصل فعلاً | ci-windows، مهمة `browsers-more` | التثبيت على جهاز المالك |
| ربط التطبيق بكل متصفح | `window_e2e.mjs` الفحوص 6 و7 و9 (مفاتيح HKCU)، `verify_installer.ps1` (المثبّت يكتبها ويزيلها) | ci-windows | — |

## 2. اكتشاف الفيديو والزر
| البند | آلي |
|---|---|
| الزر فوق المشغّل عند المرور، أعلى اليمين | فحص 1 |
| التنقّل داخل يوتيوب دون إعادة تحميل (pushState + `yt-navigate-finish`، `popstate`، Navigation API) | فحصا 3 و4 |
| يختفي في صفحة بلا فيديو ويعود بـ«رجوع» | فحص 4 |
| لا زر على فيديو صغير (إعلان/صورة مصغّرة) | `ext_e2e.mjs` |
| لا زر على DRM/EME، ولا blob/MSE خارج يوتيوب | `eligibility` في `extension/test/core.test.js` |
| الإعدادات (الموضع، الظهور الدائم) تُحفظ وتُطبَّق | فحص 5 |
| اللون والحجم والشفافية | `buttonStyle and placeButton` (وحدة)؛ **العرض الفعلي يدوي** |
| ملء الشاشة | **يدوي** (لا يُختبر آلياً) |
| استهلاك المعالج والذاكرة | **لم يُقس** للإضافة؛ قياس بدء التطبيق وذاكرته في ci-windows فقط |

## 3. قائمة التحميل
| البند | آلي |
|---|---|
| الجودات من الأطول (4320p) إلى الأقصر (144p)، الموجودة فقط | فحص 2؛ `probe_of_a_video_offers_only_available_heights_never_above_4320`؛ `video_options_are_exact_format_pairs_tallest_first_with_real_details` |
| تفاصيل كل سطر من الأداة فقط: MP4، الإطارات، الترميز، HDR، الصوت، الحجم إن عُرف | فحص 2؛ `serve_video` (ما يجيب به `probe`)؛ `normalizeOptions` |
| «مع الصوت» لا يُكتب لصيغة بلا صوت | `sdr_wins_over_hdr_and_no_audio_is_said_not_hidden`؛ `logic.test` |
| السطر المختار يُنزَّل بصيغه نفسها، ويُحفظ مع المهمة | فحص 2؛ `ipc_probe_and_add_video_through_eid_serve`؛ `exact_formats_from_the_menu_and_the_original_m4a_audio` |
| الدمج فيديو+صوت إلى MP4 | `exact_formats_from_the_menu_…` (بالأداة البديلة)؛ **بالأداة الحقيقية: سير `real-video` (PeerTube)** |
| قسم الصوت: الأصلي M4A بلا تحويل، وMP3 محوّل بلا حجم مزعوم | فحص 2؛ `audio_options_original_aac_and_converted_mp3` |
| لوحة المفاتيح (أعلى/أسفل/Home/End/Escape) | **يدوي** |
| التصميم (المسافات، عدم القص) | لقطتا شاشة من فحصي 2 و7 في ملف artifact `browser-e2e-*` |

## 4. قوائم التشغيل
| البند | آلي |
|---|---|
| `watch?v=…&list=…` يعرض القائمة، ولا تُخمَّن من رابط `watch?v=` وحده | فحص 3؛ `classifyUrl: playlists`؛ `linkPlaylist` في `logic.test` |
| «تنزيل قائمة التشغيل كاملة» آخر خيار في القائمة، وبالعدد | فحص 7 |
| يفتح القائمة كاملة في نافذة التطبيق | فحص 7 (الطلب)؛ `window_e2e` 8b (المضيف الحقيقي ← النافذة الحقيقية) |
| تطبيق بلا نافذة: تُنزَّل كلها بعملية واحدة | فحص 7 |
| اختيار بعض الحلقات أو نطاق | فحص 3؛ `ui_e2e` (النطاق)؛ `parseRange` |
| الترقيم `001 - العنوان.mp4` | `numbering_follows_the_d8_rules` واختبارات `eid-cli/tests/playlist.rs` |
| غير المتاح يُتخطّى مع السبب، الإيقاف/الاستئناف/إعادة المحاولة دون إعادة المكتمل | `eid-cli/tests/playlist.rs`، `media_jobs.rs` |
| أكثر من 100 عنصر | فحص 3 (120 عنصراً بديلاً)؛ **قائمة حقيقية كبيرة: يدوي** |

## 5. التكامل والاستقرار
| البند | آلي |
|---|---|
| الإضافة ← المضيف ← التطبيق (الطلبات الحقيقية) | `window_e2e` 8 و8b على Windows |
| التطبيق مغلق: المضيف يشغّل التطبيق المكتبي (نسخة واحدة) | `the_desktop_app_next_to_the_host_is_started_first`؛ **يدوي على جهاز المالك** |
| إعادة تشغيل التطبيق: المهام تُستأنف (الصيغة المحفوظة معها) | `media_jobs.rs` (`a_saved_running_job_loads_paused…`)، `serve_video` |
| رسائل الخطأ بالعربية والإنجليزية | `locales: en and ar have exactly the same keys` |
| لا تجاوز DRM أو حماية | `eligibility`؛ لا كوكيز ولا تسجيل دخول في الطلبات |

## 6. ما لا يمكن اختباره هنا (يجب على جهاز المالك)
1. يوتيوب الحقيقي من الإضافة (المشغّلات يُطلب منها إثبات أنها ليست روبوتاً).
2. 8K حقيقي ودمج AV1/VP9 في MP4 بالأداة الحقيقية على فيديو يوتيوب.
3. ملء الشاشة، ولوحة المفاتيح، والمظهر بالعربية.
4. Firefox 160 بالتحديد (المختبر في CI: 159.0.1).
5. استهلاك الإضافة للمعالج والبطارية.
