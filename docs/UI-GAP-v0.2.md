## ما لن ننسخه (مأخوذ من README Ezoo نفسه)
- التحديث الإلزامي الصامت (REQUIREMENTS §3: لا تحديث صامت إلزامي).

- تخزين الكوكيز وبيانات البروكسي نصاً غير مشفر.

## زر الفيديو في المتصفح — الحالة
موجود في v0.1.2 (`extension/`): زر فوق المشغّل، قائمة جودات حتى 2160p وصوت، القائمة كاملة أو اختيار عناصر.
مختبر في Chrome حقيقي حتى ملف الفيديو (Linux). **لم يُختبر يدوياً:** Edge وFirefox، وصفحة يوتيوب الحقيقية.
تخصيص الزر **موجود** في صفحة خيارات الإضافة (`extension/src/options.html`): الموضع، الحجم (مع حجم مخصص 20–64)، اللون، الشكل، الشفافية، المواقع المستثناة.
المرحلة التالية: مراجعة ما ينقص منه مقابل GAP-ANALYSIS-v0.1 البند 3، واختبار Edge وFirefox يدوياً.
