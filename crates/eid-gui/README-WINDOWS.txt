Eid Download - عيد للتحميل (Windows 10/11, 64-bit)
==================================================

التشغيل
-------
1. فك ضغط الملف EidDownload-windows-x64.zip في أي مجلد (مثلاً المستندات).
2. اضغط مرتين على EidDownload.exe.
   - إن ظهرت نافذة SmartScreen «Windows protected your PC»: اختر More info ثم Run anyway
     (البرنامج غير موقّع رقمياً بعد).
3. اضغط «إضافة تحميل»، الصق الرابط (أو عدة روابط، رابط في كل سطر)، واختر مجلد الحفظ إن أردت،
   ثم «ابدأ التحميل». يمكنك أيضاً الضغط Ctrl+V في النافذة مباشرة بعد نسخ رابط.
4. لكل تحميل: إيقاف مؤقت / استكمال / إعادة المحاولة / إزالة من القائمة / إظهار في المجلد.

ملاحظات
- التحميلات تُحفظ افتراضياً في مجلد التنزيلات (Downloads).
- إغلاق النافذة يوقف التحميلات، وتُستكمل من حيث توقفت عند فتح البرنامج مرة أخرى.
- يحتاج Microsoft Edge WebView2 (موجود مسبقاً في Windows 11 ومعظم أجهزة Windows 10 المحدّثة).
  إن لم يفتح البرنامج: ثبّت «WebView2 Runtime» من موقع Microsoft.
- إزالة تحميل من القائمة لا تحذف الملف من القرص.
- eid.exe هو سطر الأوامر لنفس البرنامج (eid add / list / pause / resume / stop يتحكم بالنافذة المفتوحة).
- eid-native-host.exe لإضافة المتصفح (لم تُنشر الإضافة بعد).
- الرخصة: MIT (LICENSE.txt). رخص المكتبات المضمَّنة: THIRD-PARTY-LICENSES.html.

Running
-------
1. Unzip EidDownload-windows-x64.zip anywhere.
2. Double-click EidDownload.exe (SmartScreen: More info -> Run anyway; the app is not signed yet).
3. "Add download", paste one or more links (one per line), optionally pick a folder, "Start download".
   Ctrl+V in the window with a copied link also opens it.
4. Per download: Pause / Resume / Retry / Remove from list / Show in folder.
Closing the window stops the downloads; they resume on the next start. Needs Microsoft Edge WebView2.
